# AI Email Writer

## Overview
An AI-powered email generation web application built using React.js and FastAPI.

## Features
- Generate professional emails using AI
- Clean React UI
- FastAPI backend
- REST API integration

## Tech Stack
- React.js
- FastAPI
- Python
- JavaScript

## Installation

### Clone the repository

git clone https://github.com/laksh-ahuja06/AI-email-writer.git

### Backend

cd backend
pip install -r requirements.txt
uvicorn main:app --reload

### Frontend

cd frontend
npm install
npm run dev

## Environment Variables

Create a `.env` file:

OPENAI_API_KEY=your_api_key
